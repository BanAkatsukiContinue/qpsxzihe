## 🛠 Troubleshooting

### Bank connection failing

```powershell
# Deactivate and reactivate
# Tools > Account List > Deactivate > Reactivate Online Services

# Update credentials
# Tools > Online Center > Enter new bank password

# Check bank status
# Quicken.com/support > Bank status (some banks have temporary issues)
```

### Transactions not downloading

```powershell
# Force update
# Tools > One Step Update > Update Now

# Check date range
# Account Details > Online Services > Download last 90 days

# Manual import
# File > File Import > Download QFX file from bank website, import
```

### Investment prices not updating

```powershell
# Update quotes
# Tools > Online Center > Update Quotes

# Check ticker symbols
# Edit Security > Verify correct ticker symbol

# Manual price entry
# Security Detail View > Enter price manually if auto-update fails
```

## 🔍 FAQ

<details>
<summary>What is Quicken Deluxe?</summary>
Quicken Deluxe is personal finance management software with bank sync, budgeting, investment tracking, bill management, and tax reporting for household budgeting, investment management, and financial planning.
</details>

<details>
<summary>Is Quicken free?</summary>
Yes, Quicken Deluxe 2026 is completely free with all features included. This is the full subscription version ($59.99/year retail) with bank sync, investment tracking, and tax reports, free of charge.
</details>

<details>
<summary>Is Quicken safe for banking?</summary>
Yes, Quicken uses read-only access to bank accounts (cannot transfer money). 256-bit encryption for data storage. Used by 20 million+ users for 30+ years. Safer than storing passwords in browser or spreadsheet.
</details>

<details>
<summary>Can Quicken replace a financial advisor?</summary>
Quicken: tracking, budgeting, investment monitoring. Financial advisor: personalized advice, tax strategy, estate planning. Quicken shows financial status but doesn't give advice. Use both—Quicken for tracking, advisor for strategy.
</details>

<details>
<summary>Does Quicken work with cryptocurrency?</summary>
Quicken tracks cryptocurrency manually (enter transactions, prices). No direct Coinbase/Binance sync. Add crypto as "Other Asset" tracking value over time. For dedicated crypto tracking, use CoinTracker or Koinly alongside Quicken.
</details>
